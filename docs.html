install + connect
# Install the SDK
$ npm install @cipher/sdk
 
# Init your first connection
$ npx cipher init
→ Detecting network topology...
→ Generating Kyber-768 keypair...
✓ Connected to 12.4M node mesh
✓ Quantum-safe session established
 
$ cipher status
NODE 0x4a2f...d91c ONLINE
PING 4ms
ALGO Kyber-768 + Dilithium3
TypeScript — first packet
import { CipherProtocol } from '@cipher/sdk'
 
const cipher = new CipherProtocol({
algorithm: 'KYBER_768',
network: 'mainnet',
})
 
// Connect + send encrypted data
const session = await cipher.connect()
await session.send({
to: 'node://0xb7f3',
data: 'Hello, ungovernable!',
})
// → 94,200 TPS, zero-trust guaranteed
